BitNet Runner

A lightweight desktop app that wraps bitnet.cpp into a plug-and-play engine, so you can run Microsoft's experimental BitNet models and chat with them fully offline. Free and open source.

Key Features:

  • Windows installer that sets up a per-user .bitnet-runner folder
  • Drop any BitNet model in .gguf format into the models folder and pick it from a dropdown
  • Built-in chat interface, no cloud or API key needed
  • Go backend with a TypeScript/JavaScript UI

ExoPlanetHunt AI

Built for the NASA Space Apps Challenge 2025 ("A World Away"). A machine-learning web app that classifies Kepler observations as a confirmed exoplanet, a candidate, or a false positive.

Key Features:

  • Single prediction from orbital period, transit duration, planet and star parameters
  • Bulk CSV classification with downloadable results
  • Insights tab with ROC curve (AUC 0.93, as reported in the repo) and confidence distribution
  • XGBoost model hosted on Hugging Face, app served with Gradio

LLM Token Counter

A simple Gradio tool for people who need to plan context limits instead of guessing. Upload a .txt or .md file, or paste text, and see characters, words and tokens per provider.

Key Features:

  • Exact counts for OpenAI (tiktoken), LLaMA 2, Mistral and Gemma tokenizers
  • Clearly labelled approximation for Claude, which has no public tokenizer
  • MIT licensed

Word Hunt: Web Hangman with Leaderboard

A browser-based Hangman game for the EF-101 course (project P01), with persistent players, difficulty levels and a leaderboard.

Key Features:

  • Three difficulty levels based on word length, with different rewards and penalties
  • Server-side word selection: the browser never receives the secret word mid-round
  • Lifetime scores and win streaks stored in PostgreSQL
  • FastAPI backend, vanilla JavaScript frontend, deployed on Vercel
